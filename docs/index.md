# Phát triển ứng dụng Web mã nguồn mở

Chào mừng đến với tài liệu hướng dẫn thực hành học phần **Phát triển ứng dụng Web mã nguồn mở**.

## Mục tiêu

Tài liệu hướng dẫn người học từng bước xây dựng một ứng dụng Web quản lý bán hàng sử dụng:

- PHP
- MySQL và MySQLi
- Bootstrap 5
- Docker Compose
- Git và GitHub
- REST API

## Lộ trình thực hành

Dự án được phát triển từng bước qua **8 hands-on**.

Mỗi hands-on kế thừa kết quả của hands-on trước, giúp người học từng bước hoàn thiện một ứng dụng Web hoàn chỉnh.
